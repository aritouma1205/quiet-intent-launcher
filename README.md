# Quiet Intent Launcher

Pixel向けに構想している、推し壁紙を主役にしたAndroidホームアプリ。
現在は初期設計の保存段階であり、実装コードやインストール可能なアプリはまだありません。

> 何もしていない時は推しだけ。何かしたい時だけUIが現れる。アプリではなく行動を選ぶ。

## この文書の位置づけ

会話「Pixelホーム画面自作方法」で検討した設計と、今回指定された項目を整理した初期ドキュメントです。
コンセプト、3層構造、操作マッピング、各パネルの基本像は提示された会話に基づきます。
元会話の全文は取得できていないため、Context Slotsの詳細、v1の線引き、例外時の挙動は本書で補った**暫定案**です。過去に合意済みの仕様とは区別します。
操作や外部アプリ連携は目標仕様であり、端末上での動作を保証するものではありません。

## 設計原則

- 壁紙を最優先にする。何も操作していないとき、UIは極力見せない。
- 必要なときだけ情報と操作を出し、終わったら静かなホームへ戻る。
- アプリ名やアイコンを探す代わりに、「撮る」「話す」などの行動を選ぶ。
- 表示する情報がなければ、その欄自体を消す。空のカードを残さない。
- 検索、全アプリ、設定への入口を確保し、目的の操作にたどり着けるようにする。
- 機能追加は「常時表示が増えないか」「アプリを探す操作に戻っていないか」で判断する。

## 3層構造

| 層 | 役割 | 内容 |
| --- | --- | --- |
| Layer 0: Quiet | 普段のホーム | 全面の推し壁紙。時計は必要なら小さく表示 |
| Layer 1: Reveal | 軽い操作で現れる情報と行動 | DO、TOOLS、TODAY、GLANCE、Context Slots（暫定） |
| Layer 2: Deep | 詳しい操作と逃げ道 | Universal Search、すべてのアプリ、設定、ホーム編集 |

Quietにはアプリアイコン、検索バー、固定Dock、天気、予定を常設しません。
時計を置く場合も壁紙を邪魔しない位置にし、無操作時に消す案を残します。

## 操作マッピング

| 操作 | 動作 |
| --- | --- |
| 右端から内側へスワイプ | DOパネルを表示 |
| 左端から内側へスワイプ | TODAYパネルを表示 |
| 画面中央をタップ | GLANCEを一時表示 |
| 上スワイプ | Universal Searchを表示 |
| 下スワイプ | 通知画面を表示 |
| ホームの空き領域を長押し | ホーム編集 |
| ホームの空き領域をダブルタップ | 画面OFF |

この表はホーム上の操作です。アクション項目の長押しは、その項目の選択肢を開きます。
単タップとダブルタップの判定、縦スワイプとエッジ操作の優先順位は実装前に調整します。

## DO — 行動を選ぶ

右端から引き出す、日常操作の中心となるパネルです。

| 行動の例 | 通常タップの例 |
| --- | --- |
| 撮る | カメラを開く |
| 話す | ChatGPTを開く |
| 聴く | 音楽アプリを開く |
| 見る | 動画・閲覧用アプリを開く |
| 移動する | 地図アプリを開く |
| 調べる | 検索用アプリを開く |

行動には起動先を紐付け、通常タップは既定の行動をすぐ実行します。
長押しすると派生操作を表示します。たとえば「撮る」なら、写真・動画・QR・Google Lensを候補にします。
これらは連携の候補であり、各アプリ内の特定機能を直接開けるかは別途確認します。

**暫定案:** 起動先はユーザーが変更できるものとします。未設定・未インストールの場合は説明と再設定への入口を表示し、無反応にしません。

## Panels風エッジ操作とTOOLS

Panels風の「端から必要な機能を引き出す」操作をホームに統合します。
普通の左右スワイプではなく、画面端を起点とする内向きのスワイプを使います。
他アプリ上への常駐オーバーレイは、この初期設計には含めません。

右端を浅く引くとDOを表示し、さらに深く引くとTOOLSまで展開する構想です。
最初から大量に並べず、引き出す深さで表示する機能量を変えます。

```text
右端 → 浅く引く → DO
                  撮る / 話す / 聴く / 移動する …
       深く引く → TOOLS
                  ライト / 電卓 / QR / タイマー / スクリーンショット
```

TOOLSは短時間で使う道具の領域です。上記は候補であり、すべてをv1必須とはしません。
引き出し距離、反応する端の幅・高さ、左右の配置は実機で決めます。
Androidの「戻る」操作との競合、片手での届きやすさ、誤操作の少なさを確認対象にします。

**暫定案:** パネル外タップや戻る操作で閉じてQuietへ戻れるようにし、深いスワイプが難しい場合にはTOOLSを開く明示的な操作も用意します。

## TODAY — 今日の情報

左端から開き、日付・曜日、天気、次の予定、バッテリー残量を確認します。

```text
TODAY
22 SEP / TUE
24°C
NEXT  23:00 予定名
BATTERY  72%
```

表示値はイメージです。予定がなければNEXT欄そのものを表示しません。
天気や予定の取得元、更新間隔、必要な権限は未決定です。
**暫定案:** 権限がない項目は表示せず、設定から有効化できるようにします。取得失敗時に古い情報を最新として見せない方針とします。

## GLANCE — 一瞬だけ見る

画面中央のタップで、時刻・日付・天気・バッテリー残量を軽く表示します。
TODAYを開くほどではない短い確認用です。
2〜3秒操作しなければフェードアウトし、壁紙だけに戻ります。
天気など取得できない情報は省略します。表示位置や正確な消去時間は調整対象です。

## Universal Search — 目的への逃げ道

上スワイプで開く、アプリ・Web・操作をまとめて探す入口です。
入力欄の呼びかけは「何をする？」を想定します。

| 入力例 | 結果・選択肢の例 |
| --- | --- |
| youtube | YouTube、YouTube Music、YouTubeを検索 |
| 福岡 天気 | Web検索、ChatGPTに聞く |
| 写真 / 電卓 / 音楽 / 設定 | 対応するアプリや操作 |

入力前には「最近」と「すべてのアプリ」への入口を置く構想です。
通常のホームにアプリ一覧は置かず、検索画面から必ず開けるようにします。
「最近」の収集方法・保存範囲と、検索結果の並び順は未決定です。

**暫定案:** v1の目的語検索は、ユーザーが設定する行動名・別名とアプリ名の検索から始めます。自然言語の意図推論は必須にしません。
Web検索やChatGPTへの送信は選択したときだけ行い、入力中の文字列を自動送信しない方針とします。
特定アプリへの検索語引き渡しに対応できない場合は、アプリ起動などの代替を検討します。

## Context Slots — 状況に応じた少数の候補（暫定案）

今回の保存対象として指定された要素ですが、提供された会話抜粋には詳細がありません。
以下を議論用の初期案として残します。

- Reveal内の小さな枠に、その状況で役立つ行動だけを表示する。Quietの常設表示は増やさない。
- 例: イヤホン接続時は「聴く」、予定が近ければ「予定を見る」、移動前には「経路を見る」。
- 候補がなければ枠自体を消す。ユーザーが設定したDOの基本配置は自動で並べ替えない。
- 行動はユーザーの選択で実行し、勝手にアプリを起動しない。
- v1では手動設定の少数枠までを候補とし、時刻・機器接続・予定・位置情報などによる自動切替は将来拡張とする。

配置先（DOまたはTODAY）、枠数、条件の優先順位、必要な権限は未決定です。

## 見た目と動き

カードを大量に浮かべる構成は避けます。
操作すると背景が少し暗くなり、細い文字とアイコンが現れ、操作終了で消える見た目を目指します。
暗い半透明レイヤーとごく軽いBlurを候補にし、壁紙を強くぼかし切らない方針です。
アニメーションは「壁紙の奥からUIが浮き上がる」感覚に統一します。
正確な時間・曲線は未決定です。文字の可読性、タップ領域、動きを減らす設定への配慮も検討します。

## v1スコープ（暫定案）

v1の目的は「壁紙だけのホームから、行動・必要な情報・全アプリへ迷わず到達できる」体験の成立です。

| 区分 | 範囲 |
| --- | --- |
| 中核 | Quiet、DOの既定アプリ起動と紐付け編集、TODAYとGLANCEの時刻・日付・バッテリー、基本的な検索と全アプリ一覧 |
| 操作 | 左右エッジ、中央タップ、上スワイプ、ホーム編集。閉じる操作でQuietへ戻る |
| 最小限の設定 | 壁紙を主役にする表示設定、行動の名前・起動先・検索用別名 |
| 実機検証後に採否を決める | DO長押しの派生操作、深く引くTOOLS、通知画面表示、ダブルタップ画面OFF |
| 任意・未確定 | TODAY/GLANCEの天気、次の予定、「最近」、手動Context Slots |

操作マッピングは目標として維持しますが、上表の条件付き機能は実現方法と権限を確認してからv1に含めます。
技術スタック、対応Androidバージョン、配布方法、外部サービスはこの段階では決めません。

### v1の確認観点

- 無操作時に不要なUIが壁紙を覆わない。
- DOから設定したアプリを起動でき、検索から全アプリへ到達できる。
- TODAYの空欄は消え、GLANCEは設定した時間で閉じる。
- パネルを閉じてQuietへ戻れる。
- 起動先の不在、情報未取得、権限未許可でも基本のホーム操作が使える。
- エッジ操作がシステム操作と競合しないか、単タップ・ダブルタップ・長押しが誤発火しないか実機で確認する。

## 将来拡張

- 時刻、機器接続、予定などによるContext Slotsの自動切替。
- TOOLSの追加と、対応アプリの特定機能を直接開く連携。
- 天気・予定・最近の行動の統合と表示条件の調整。
- 目的語の別名拡充、検索順位の改善、必要性が確認できた場合の意図理解。
- エッジの位置や感度、時計の配置、フェード時間などの個人調整。

いずれも常時表示を増やさず、必要なときだけ現れるという原則を守ります。

## 実装前に確認すること

1. Pixel実機でのエッジ操作とシステムジェスチャーの共存方法。
2. 通知画面表示・画面OFF・スクリーンショットの実現方法と権限、通常のロック解除への影響。
3. カメラ、QR、Google Lens、ChatGPTなどへの連携で可能な起動先と代替操作。
4. 天気・予定の取得元、権限、更新失敗時の扱い。
5. Context Slotsの意味・配置・枠数と、v1の最終的な採用範囲。

本書は設計の出発点です。未検証の連携や暫定案を実装済み・確定済みとして扱いません。
