# Quiet Intent Launcher

Pixel向けに設計している、推し壁紙を主役にしたAndroidホームアプリです。
**現在は設計段階です。実装コード・APK・実機での動作実績はまだありません。**

> 何もしていない時は推しだけ。何かしたい時だけUIが現れる。アプリではなく行動を選ぶ。

設計の全体は **[v1設計書](docs/design-v1.md)** にまとめています。画面遷移、操作の判定、機能、初期値、権限、保存データ、失敗時の挙動、受入条件を含みます。

## 設計の軸

- 壁紙を主役にし、情報と操作は必要なときだけ表示する。
- アプリ名を探す代わりに「撮る・話す・聴く」などの行動を選ぶ。
- 情報がなければ欄ごと消し、空カードを残さない。
- 検索・全アプリ・設定への入口を必ず残す。

| 層 | 役割 | 内容 |
| --- | --- | --- |
| Quiet | 普段のホーム | 壁紙＋左右の操作バー。小時計は任意 |
| Reveal | 必要なときだけ開く | DO、TOOLS、TODAY、GLANCE、Context Slots |
| Deep | 探す・編集する | Universal Search、全アプリ、ホーム編集、設定 |

## 操作マッピング

| 操作 | 動作 |
| --- | --- |
| 右端の表示バーから内側へスワイプ | DOを開く |
| 左端の表示バーから内側へスワイプ | TODAYを開く |
| 中央などの空き領域をタップ | GLANCEを一時表示 |
| 空き領域を上スワイプ | Universal Search |
| 空き領域を下スワイプ | 通知画面（機能有効化後） |
| 空き領域を長押し | ホーム編集 |
| 空き領域をダブルタップ | 画面OFF＝システムロック（機能有効化後） |

**エッジ操作は表示バーの範囲からしか開始できません。** バーのない端や中央からスワイプしても開きません。バーの表示と操作領域を一致させ、位置・長さ・太さ・濃さを調整できます。バーのタップでも開けます。

Panelsのバー起点の操作を参考にし、ホーム内へ統合する設計です。他アプリの上にはバーを表示しません。

## 各機能

| 機能 | 仕様の要点 |
| --- | --- |
| DO | 撮る・話す・聴く・見る・移動する・調べる。名前と起動先を編集でき、長押しで派生操作 |
| TOOLS | ライト、電卓、QR用アプリ、タイマー、ホームのスクリーンショット |
| TODAY | 日付・曜日・バッテリー、任意で天気と次の予定。空欄は表示しない |
| GLANCE | 時刻・日付・バッテリー・取得済みの天気。初期3秒で消去、時間と位置を変更可能 |
| Universal Search | 行動名・別名・アプリ・道具・設定のローカル検索と、明示操作によるWeb検索・ChatGPTへの共有 |
| 全アプリ | 個人プロファイルの起動可能なアプリを表示。検索画面から到達 |
| Context Slots | DO内に最大2件。手動固定または曜日・時刻の規則で行動を表示。空枠は消す |

**TOOLSの開き方は設定で選べます。**

- **タップで展開（初期値）:** DOを開いてTOOLSボタンを押す。
- **深く引いて展開:** 右バーから深く引くとTOOLSまで展開。深さを調整できる。

どちらの設定でもTOOLSボタンを残します。深さでの展開は、バーから始めたドラッグだけに適用します。

## v1の範囲

個人利用のPixel、Android 12以上、個人プロファイルを対象にします。
Quietとバー、DOと派生操作、TOOLSの両方式、TODAY・GLANCE、検索・全アプリ、Context Slots、編集・設定・操作補助を設計対象とします。

天気・予定・通知・画面OFF・スクリーンショットは個別に有効化します。権限を与えなくてもホームの中核機能は使えます。天気は手動で地域を選択し、位置情報の常時取得は行いません。

Kotlin＋Jetpack Compose、単一アプリモジュール、ローカルのDataStoreを基本構成とします。外部アプリ連携は公開API・公開ショートカットを使い、未対応時は説明と起動先の変更で対処します。

具体的な初期値と検証条件は[v1設計書](docs/design-v1.md)を参照してください。実機検証が必要な項目は、設計済みの挙動と区別して記載しています。

## 将来拡張

- イヤホン接続・予定・移動状況に応じたContext Slots。
- 他アプリ上でのバー、仕事用プロファイル・プライベートスペース対応。
- ウィジェット、設定のバックアップと移行、壁紙切替、Blurなどの視覚調整。
- 必要性が確認された場合の検索の意図理解。

v1では常駐オーバーレイ、AI推論、クラウド同期、独自チャット画面は実装対象にしません。
